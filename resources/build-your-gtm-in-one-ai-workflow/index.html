The overview

About this guide

It covers setup, the market, your best-fit customer, the offer, AI visibility, positioning, channels, sales, tracking and the return from your AI tools. A worked example shows the sequence from the company profile to a 13-week calendar. It is a planning process with real inputs, not a promise of a complete strategy in one prompt.

Inside the guide

What's inside

  1. Project setup and company profile

    Instructions for the Claude project and a one-page company profile template.

  2. Ten stages, in order

    What to collect, a prompt to run and the decisions to make at each stage.

  3. A worked example

    The guide follows Fellgate IT through the stages so you can see how later findings change earlier conclusions.

  4. A 90-day plan and calendar

    A final prompt combines the stage summaries into priorities, owners, a 13-week calendar and a weekly scorecard.

  5. Limits from the test run

    Where AI answers ran long, personalisation affected results and citations needed checking.

A few questions

Before you start.

Which AI tool is this written for?

The guide is built around Claude Projects with web search. It notes that ChatGPT Projects can also work, and the AI visibility stage uses other assistants for the test runs.

What information do I need?

Your company profile, won and lost deals, customer interviews or reviews, website copy, channel costs, sales-process details and the AI tools you use. Each stage lists its inputs.

Do I run all ten stages in one chat?

Yes. Run them in order in the same project and chat. Later stages reuse earlier findings, and the final prompt combines the stage summaries into the plan.
